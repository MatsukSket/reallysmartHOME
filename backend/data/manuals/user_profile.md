# Профиль жильцов и правила умного дома

## Пользователь: Алексей
Предпочтения:
- Не любит яркий верхний свет в вечернее время.
- Комфортная температура для сна (после 23:00) составляет 19°C.

## Глобальные сценарии безопасности
Режим "Никого нет дома" (Away mode):
- Включается автоматически, если датчики движения не фиксируют активность более 2 часов.
- При активации режима необходимо перекрыть главный кран водоснабжения (ID: water_valve_main) для предотвращения протечек.
- Температура всех обогревателей снижается до 15°C для экономии энергии.

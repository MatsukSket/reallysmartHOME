Отдельные записки Шепелевич, Рассохова и Дороша по указанным именам не обнаружены среди доступных вложений. Для этих частей основанием служат требования задания и исходники компонентов.

## Команды

- Из `backend/` — `python -m pytest -o addopts='' -q`.
- Из `iot_gateway/` — `python -m pytest -o addopts='' -q`.
- Из корня — `python -m pytest -q tests/integration`. Установка зависимостей — `python -m pip install -r requirements/check.txt`.
- Статика — `python demo.py --build-ui` и `node --check frontend/public/home.js`.
- Индекс — `python -m app.rag.indexer` из `backend/`.
- Реальная сцена — `python -m pytest -q tests/integration/test_browser.py`, с `SHOW_BROWSER=1` и `SCENE_EXE` с путём к Godot. Для Chroma и Ollama используйте также `CHECK_ASSISTANT=ollama`.

На Windows отдельно запущен `python demo.py` в чистом окружении Python 3.13 с `requirements/demo.txt` и отдельной базой. Проверены главная страница, OpenAPI, панель шлюза и фактическое включение кондиционера. Сборка Chroma успешно выполнена с локальными весами MiniLM. Записки использованы для согласования требований, а результат зафиксирован по проверкам сборки.

Проверка Linux и macOS в текущем окружении недоступна. Подключение реальных приборов вне сценария демонстрации. Общий запуск использует рабочую базу в `runtime/`.

## Фактические результаты на Windows

- **Backend:** 191 тест прошёл. **Шлюз:** 14 тестов прошли.
- **Сквозные проверки:** 5 прошли. Для процессов демо использовано чистое окружение только с `requirements/demo.txt`. В Edge проверены SSE и восстановление снимка после перезапуска сервера; с эмулятором проверены команды, блокировка, цель и защита при протечке.
- **Godot 4.7.2 + Edge + Chroma + Ollama:** один совместный тест прошёл за 72 с. Включение в браузере изменило состояние сцены. Сценарий вызвал E04 в Godot; браузер получил ошибку и объяснение о падении давления с источником `boiler_baxi.md#boiler_baxi-4`. Проверка использовала `CHECK_ASSISTANT=ollama`, `OLLAMA_NUM_GPU=0`, `SHOW_BROWSER=1` и `SCENE_EXE`.
- Первые вызовы Ollama в режиме GPU завершились по старому таймауту 45 секунд. Интерфейс показал недоступность модели. Прогон с CPU и лимитом 90 секунд прошёл. Ранее выявленные несовместимости числового msg_id и имени параметра маршрута подтверждения исправлены.
- Подготовлен сценарий предварительной записи. Браузер и Godot запускались рядом, видеофайл в проверках не создавался.

После реорганизации повторно прошли 191 тест backend, 14 тестов шлюза, 5 сквозных тестов и браузерная проверка со сценой Godot в режиме demo. Проверены относительные ссылки Markdown, ресурсы Godot, подключение файлов зависимостей и совпадение собранной статики с исходной. Проверка с реальной Ollama выше относится к предыдущему прогону.

### Проверка после ревизии рабочего дерева

- Windows: 191 тест решателя, 16 тестов шлюза и 7 интеграционных тестов прошли.
- Отдельный браузерный прогон с Godot проверил добавление и удаление прибора, изменение физических показаний, обновление карточек и отказ при отсутствии питания.
- Сборка статики, синтаксис Python и JavaScript, ссылки документации и ресурсов Godot, разбор JSON и YAML и `pip check` прошли. Проверка с Godot использовала режим `demo`. Режим Ollama и реальные приборы в этом прогоне не проверялись.
